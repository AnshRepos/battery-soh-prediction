===============================================================================================================
Artifactory Client Scripts
===============================================================================================================
(1) Uploads binaries to artifactory
(2) Downloads binaries from artifactory
(3) Move/copy artefacts between repositories
(4) Promotes artefacts from source to target repository
(5) Set retention properties

System Requirements
===============================================================================================================
(1) Perl (v > 5.16)
(2) Curl 
(3) md5sum and sha1sum (for Linux and Cygwin environment)
(4) md5 and shasum (for Mac environment)
