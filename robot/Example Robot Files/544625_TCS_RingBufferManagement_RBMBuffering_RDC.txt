Test Case TC-544625: TCS_RingBufferManagement_RBMBuffering_RDC
Pre-Condition
Power-up the ECU, Voltage=12V, KL30 is connected.
Flash the Release SW using the flashing script.
Check if PUTTY is available in Testbench and make necessary SSH and serial connections.
Test Case Design
Architecture Baseline Version: ??

Step 1:

Input Operation: Power cycle the ECU from PowerOff to PowerON.
Expected Result: ECU is turned OFF, then ECU is turned ON.
Actual Results: ECU is turned OFF, then ECU is turned ON.
Step 2:

Input Operation: Execute the ADISS stub application in SSH using command:
cd /usr/sbin
./stub_adiss
Expected Result: Stub is executed without any errors.
Actual Results: Stub is executed without any errors.
Step 3:

Input Operation: Verify the API RBM_GetVersion().
Expected Result: Returns the application version.
Actual Results: Returns the application version.
Step 4:

Input Operation: ADISS application to enter into StandBy state using:
RBM_CreateBufswContent()
Example: RBM_CreateBufswContentTest /opt/asw/bin/ADISS_ringbuffer_config.json
RBM_EnterStandby()
Expected Result: Return value = 0 (RBM_ok).
Actual Results: Return value = 0 (RBM_ok).
Step 5:

Input Operation: Enter into RBM_Buffering state using API RBM_StartBuffering().
Expected Result: Return value = 0 (RBM_ok).
Actual Results: Return value = 0 (RBM_ok).
Step 6:

Input Operation: Execute the SDSRDC stub application in SSH using command:
cd /usr/sbin
./stub_sdsrdc
Expected Result: Stub is executed without any errors.
Actual Results: Stub is executed without any errors.
Step 7:

Input Operation: Verify RBM_GetState() for RDC application.
Expected Result: Return the Current State = RBM_StartBuffering (2).
Actual Results: Return the Current State = RBM_StartBuffering (2).
Step 8:

Input Operation: Verify the API RBM_RegCallBack() and RBM_ReqCbk() (e.g. RBM_ReqCbk 1 for store size).
Expected Result: Return value = 0 (RBM_ok).
Actual Results: Return value = 0 (RBM_ok).
Step 9:

Input Operation: Verify the API RBM_trigSingleEvtRecRDC() with parameters:
<priority> <preEventTime> <postEventTime> <listofPDUs> <filename> <len> <data>
Example: RBM_trigSingleEvtRec 20 10 10 443,5905 metaSin 5 abcde
Expected Result:
Return value = 0 (RBM_ok)
Returns Trigger_State = PreEvent (0) / PostEvent (1) / Finished (2) / Cancelled (3)
EUUID is created
Returns Trigger Handle
Actual Results:
Return value = 0 (RBM_ok)
Returns Trigger_State = PreEvent (0) / PostEvent (1) / Finished (2) / Cancelled (3)
EUUID is created
Returns Trigger Handle
Step 10:

Input Operation: Verify the API RBM_AddMetaData() with parameters:
<euuid> <filename> <len> <data>
Example: RBM_AddMetaData <euuid id generated from the above step> metaAdd 3 abc
Expected Result: Return value = 0 (RBM_ok).
Actual Results: Return value = 0 (RBM_ok).
Step 11:

<euuid>
